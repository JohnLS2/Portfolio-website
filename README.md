# John Leonard Salas — Personal Portfolio Website 🚀

A modern developer portfolio built with **React 19**, **Vite 8**, and modern **CSS design tokens**.

![Portfolio Preview](./public/hero-bg.jpg)

## ✨ Features

- **Modern Glassmorphism & Cyber Aesthetic:** Curated dark theme (`#0a0a0f`), vibrant gradients, neon ambient glow, and frosted glass cards.
- **Dynamic Role Typewriter:** Fluid typing/deleting animation cycling through developer specialties.
- **Interactive Code Block & Stats:** Developer profile expressed as a syntax-highlighted code editor window.
- **Services & Skills Showcases:** Categorized technical arsenal with animated proficiency meters.
- **Live Coding Journey Clock:** Real-time ticker counting years, months, days, hours, and ticking seconds since May 28, 2021.
- **Filterable Project Showcase:** Interactive category filtering (All, Featured, Web Apps, Tools, UI & Landing) with image preview modals and live GitHub/demo links.
- **Contact Hub:** Interactive direct message form, one-click email copy with clipboard feedback, and social links.
- **Responsive & Accessible:** Fluid typography, reduced motion support, semantic HTML5, and schema.org JSON-LD SEO markup.

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Bundler:** [Vite 8](https://vite.dev/)
- **Styling:** Vanilla CSS with Custom Properties & Glassmorphism Design Tokens
- **Typography:** [Inter](https://fonts.google.com/specimen/Inter) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- **Deployment:** GitHub Actions automated CI/CD to GitHub Pages

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

```bash
# Clone the repository
git clone https://github.com/JohnLS2/Portfolio-website.git

# Navigate into project directory
cd Portfolio-website

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Building for Production

```bash
npm run build
```

The output bundle will be generated in the `dist/` directory.
